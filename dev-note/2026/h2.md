## 7.18

### 错误记录

#### [go] 错误使用`range`

**现象：** 把 Python 的写法记混了，写成了`for i in range(10):`

**解决：** `for i := range 10`或直接`for range 10`

#### [go] 创建切片错误

**现象：** 

```go
func Pic(dx, dy int) [][]uint8 {
	result := make([][]uint8, dy, dx)
	for i := range dy {
		for j := range dx {
			result[i][j] = uint8(dx ^ dy)
		}
	}
    return result
}
```

**原因：** 

1. `result := make([][]uint8, dy)`

这一步创建：

一个长度为 dy 的外层切片；
外层底层数组有 dy 个元素；
每个元素类型是 []uint8，初始值都是 nil。

2. `for y := 0; y < dy; y++ {
	result[y] = make([]uint8, dx)
	}`

这一步为每一行分别创建一个长度为 dx 的 uint8 底层数组，并让 result[y] 引用它。

**解决：** 

```go
func Pic(dx, dy int) [][]uint8 {
	result := make([][]uint8, dy)
	for i := range dy {
		result[i] = make([]uint8, dx)
		for j := range dx {
			result[i][j] = uint8(dx ^ dy)
		}
	}
	return result
}
```

## 7.19

### 错误记录

#### [go] `String() string` 方法没有返回字符串

**现象：** 

为 `IPAddr` 实现 `fmt.Stringer` 时，在 `String()` 方法中使用 `fmt.Printf` 直接输出，编译报错：`missing return`

**原因：** 

String() 方法要求返回一个 string：

func (ip IPAddr) String() string

fmt.Printf 只会把内容输出到终端，不会返回格式化后的字符串，因此不能满足方法签名。。

**解决：** 

使用 fmt.Sprintf 生成并返回字符串：
```go
func (ip IPAddr) String() string {
	return fmt.Sprintf(
		"%d.%d.%d.%d",
		ip[0], ip[1], ip[2], ip[3],
	)
}
```
Printf 用于直接打印，Sprintf 用于生成字符串。

## 7.20
### 错误记录

#### [Go/for] 在初始化部分写两组 `:=`

**现象：** 在 `Same` 中尝试同时读取两个 channel，`for val1, ok1 := <-ch1, val2, ok2 := <-ch2; ...` 编译失败。

**原因：** `for` 初始化部分只能是一条简单语句，不能包含两组独立的 `:=`。

**解决：**

```go
for {
	val1, ok1 := <-ch1
	val2, ok2 := <-ch2
}
```

#### [Go/channel] 遍历结束后接收操作一直阻塞

**现象：** `Walk` 已发送完树中的所有值，但 `Same` 再次执行 `val, ok := <-ch` 时一直阻塞，`ok` 没有变成 `false`。

**原因：** `ok` 只有在 channel 已关闭且数据已读完时才为 `false`；发送结束不等于 channel 自动关闭。

**解决：** 在 `Walk` 完整执行后，由发送方关闭 channel：

```go
go func() {
	Walk(t1, ch1)
	close(ch1)
}()
```

#### [Go/二叉搜索树] 用前序遍历比较树中元素

**现象：** 两棵树包含相同元素，但树形不同时，逐个比较可能返回 `false`。

**原因：** 前序遍历结果受树形影响；二叉搜索树的中序遍历才能稳定得到升序序列。

**解决：**

```go
Walk(t.Left, ch)
ch <- t.Value
Walk(t.Right, ch)
```
