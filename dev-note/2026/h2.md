#### [go] 无类型常量

常量不能使用 := 语法声明。

正确写法：

```go
const MaxRetry = 3       // 无类型常量

const Timeout int = 30  // 有明确类型
```

> 不能用`:=`。实际开发中，普通固定值通常写成无类型常量；只有接口、协议或业务明确要求某种类型时，才显式标注类型。
>
> 
>
> 无类型数值常量在编译期可以保存非常大的高精度数值，只有当它被放进某个具体类型时，编译器才检查能不能装下。

#### [go] switch与其他语言区别

Go 的 switch case 不必是常量， 所涉及的值也不必是整数。

每个 case 末尾所需的 `break` 语句 在 Go 中是自动提供的，只运行被选中的 case，而不会继续执行后面的 case。

```go
switch os := runtime.GOOS; os {
	case "darwin":
		fmt.Println("macOS.")
	case "linux":
		fmt.Println("Linux.")
	default:
		// freebsd, openbsd,
		// plan9, windows...
		fmt.Printf("%s.\n", os)
	}
```
#### [go] swich true

没有条件的 switch 与 switch true 相同。
这种结构可以干净地写出很长的 if-then-else 链。
实际开发中，无条件 switch 很适合表示多个互斥的范围判断：
```go
switch {
case t.Hour() < 12:
	fmt.Println("Good morning!")
case t.Hour() < 17:
	fmt.Println("Good afternoon.")
default:
	fmt.Println("Good evening.")
}
```
等价于
```go
if t.Hour() < 12 {
	fmt.Println("Good morning!")
} else if t.Hour() < 17 {
	fmt.Println("Good afternoon.")
} else {
	fmt.Println("Good evening.")
}
```
switch true更加优雅
